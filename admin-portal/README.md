# NBN Admin Portal (மத்திய நிர்வாக கன்சோல்)

## கண்ணோட்டம் (Overview)
இது **NBN - Nuvea Business Network**-ன் மத்திய நிர்வாக (Super Admin) தளம் ஆகும்.
இங்கு அனைத்து சாப்டர்கள், உறுப்பினர்கள், வாடிக்கையாளர்கள், மற்றும் சந்தை (Marketplace) செயல்பாடுகளை ஒரே இடத்தில் கட்டுப்படுத்த முடியும்.

## ஃபைல் கட்டமைப்பு (File Structure)
- `index.html`: அட்மின் தளத்தின் பிரதான HTML பக்கம் மற்றும் லேஅவுட்.
- `js/admin-app.js`: அட்மின் செயல்பாடுகள், API தொடர்புகள் மற்றும் டேஷ்போர்டு லாஜிக்.
- `css/admin.css`: பிரத்யேக அட்மின் ஸ்டைல்கள்.

## முக்கிய தொகுதிகள் (Core Modules)
1. **கண்ணோட்டம் (Overview):** உறுப்பினர்கள் எண்ணிக்கை, சாப்டர்கள் நிலை மற்றும் வர்த்தக அளவுகள்.
2. **பயனர்கள் & பதிவுகள் (User Management):** 
   - Option A (Networking + Marketplace)
   - Option B (Marketplace Only)
   - Option C (Customer)
   - Super Admin கணக்குகளை சரிபார்த்தல், அனுமதித்தல் (`REG-...`), இடைநிறுத்தம் (Suspend) செய்தல்.
3. **சாப்டர்கள் & ஏகபோக சீட்கள் (Chapters & Monopoly):** 100 தொழில் பிரிவுகளுக்கான தாலுகா வாரியான சீட்கள் & காலியிடங்கள்.
4. **மார்க்கெட்பிளேஸ் கட்டுப்பாடு (Marketplace Oversight):** தேவைகள், கொட்டேஷன்கள் மற்றும் 18% GST இன்வாய்ஸ் வர்த்தகங்கள்.
5. **ஒழுங்கு & கூட்டங்கள் (Discipline & Strikes):** 3-ஸ்ட்ரைக் விதிகள் மற்றும் வாராந்திர கூட்டம் மேலாண்மை.
6. **கணினி அமைப்புகள் (System Settings):** கட்டணங்கள் மற்றும் GST சதவீத அமைப்புகள்.

## எப்படி இயக்குவது? (How to access)
பிரதான சர்வர் இயங்கும் போது:
`http://localhost:3000/admin` என்ற URL-ஐ பிரவுசரில் திறக்கவும்.
